# Customer Behavior Analysis Project

## Overview

This project demonstrates an end-to-end data analytics workflow, from data preparation to business insights. The analysis includes loading data with Python, performing exploratory data analysis (EDA), cleaning and transforming the dataset, querying the data using SQL Server, building an interactive Power BI dashboard, and summarizing key findings in a final report.

---

## Dataset

The project uses a structured dataset containing records for analysis. The data is cleaned and prepared before being used for SQL analysis and dashboard visualization.

---

## Tools & Technologies

* **Python** (Pandas)
* **SQL Server** (T-SQL)
* **Power BI**
* **Jupyter Notebook**
* **Git & GitHub**

---

## Project Steps

### 1. Load Data

* Import the dataset (CSV) into Python.
* Inspect data structure and data types.
* Check for missing values and duplicates.

### 2. Exploratory Data Analysis (EDA)

* Generate descriptive statistics.
* Analyze distributions and relationships.
* Create visualizations to identify trends and patterns.

### 3. Data Cleaning

* Handle missing values.
* Remove duplicate records.
* Correct data types.
* Prepare the dataset for analysis.

### 4. SQL Analysis

* Import the cleaned dataset into SQL Server.
* Write SQL queries to answer business questions.
* Perform filtering, aggregation, joins, and ranking.

### 5. Power BI Dashboard

* Connect Power BI to the processed dataset.
* Build interactive charts and KPIs.
* Create filters and slicers for user exploration.

### 6. Final Report

* Summarize the analysis.
* Present key insights and recommendations.
* Highlight business trends discovered during the project.

---

The Power BI dashboard provides:

## Results

The project demonstrates how raw data can be transformed into meaningful business insights through data cleaning, SQL analysis, and interactive visualization. The final dashboard and report support data-driven decision-making by presenting clear and actionable findings.

---

## How to Run

1. Clone this repository.
2. Install the required Python libraries.
3. Open the Jupyter Notebook.
4. Run the notebook to clean and analyze the dataset.
5. Import the cleaned data into SQL Server and execute the SQL scripts.
6. Open the Power BI file to explore the interactive dashboard.
